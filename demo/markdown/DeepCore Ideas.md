# DeepCore Ideas & Brainstorming

## Dynamic UI Cards
Use declarative JSON/YAML formats to describe interactive views that modules can load dynamically. This keeps the core UI decoupled from third-party styling.

## Local LLM Calibration
We can write specialized prompt packs to optimize local LLM models (e.g. Qwen-2.5 or Llama-3) for extraction.
