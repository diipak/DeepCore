# DeepCore Architecture Notes

## Deterministic Boundary
Keep the parser and indexer purely rule-based and deterministic. Probabilistic model inference must only occur at the Discoveries and Understanding stages.

## Time Evolution
Objects and relationships decay in confidence over time if not refreshed. Ensure the schema supports temporal stamps on relationships and content hashes.
